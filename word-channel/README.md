# word-channel (Module)

A declared table of values — bytes, ranged floats, bools — replicated to every remote client over a synced channel narrower than the table, with late-join support and a declared refresh cadence. A generator mints the controller from a word-table config (`generate.py`), so the shipped module is one worked configuration: 2 bytes + a ranged float + 4 bools (28 payload bits) over **21 synced bits**, full refresh ~0.23 s at 60 fps — two batches, each holding 0.1 s plus one guaranteed frame.

## Provenance

The protocol is the VRCFury Parameter Compressor's (source-studied from `com.vrcfury.vrcfury`: 0.1 s batch cadence plus a guaranteed extra frame, a synced index the receiver routes on, latch double-buffering), generalized to a declared word table and hardened where the pause fixture below broke it. VRLabs **Custom-Object-Sync** (MIT, © VRLabs) is the studied ancestor whose receive-side design this entry rejects: its multi-frame receiver decode walks are the machinery a culling pause interrupts, so here every receive state decodes in one parameter-driver frame. Nothing is ported from either; both are credited as ancestors.

## Ground truth

- The word table, the wire, the batch walk, and every parameter's type and role: `controller.yaml`, emitted by `generate.py` from its `CONFIG` block. `generate.py` owns both — its docstring is the design record (the protocol argument, the four assumptions `Acquired`'s certification rests on and which one is unmeasured, and the `build(config)` contract for a generator composing this channel into its own controller), and each `CONFIG` knob carries its direction and its change-trigger in the comment at the value. The published set is the prefab's `globalParams`.
- **`WordChannel/Acquired` is the proposition a consumer gates on**, and its scope is narrower than it reads: it does **not** fall for a receiver wedged in `Lost`, for a producer that stopped writing, or for a consumer's own enable being off. Its pause coverage is exactly `IsAnimatorEnabled`'s, which `../../docs/runtime.md` §Parameters tabulates per cull mechanism — view cull is the uncovered one, and closing it is the consumer's call to compose `anti-cull`. It also says nothing about whether the applied table is one **coherent** snapshot: an aliased resume yields the whole-word mix measured below, never a missing batch.
- `WordChannel/Cycle` is emitted but deliberately off `globalParams`, so a merged build renames it `VF##_WordChannel/Cycle` with `##` assigned per build. It is a session-local reading for a fixture or the emulator's runtime mirror and **never an address anything may bind**; a `globalParams` name is capturable, and a host avatar declaring this one would take it over with *its* synced and saved flags winning and no build error (`../../docs/gimmicks.md` §Packaging and interface).
- **VRCFury's Parameter Compressor never touches the wire params**, even on an overflowing host avatar: it compresses only menu-driven params (`ParameterCompressorSolverService.GetParamsToOptimize` skips any param not `usedInMenu`), so double-multiplexing cannot arise.
- **Seam**: VRCFury `FullController` on the prefab root; no scene bindings, no anchor — the module is pure animator machinery and composes anywhere under the avatar. `basis: mount-root` ↔ the `FullController` default `rootBindingsApplyToAvatar: 0` is the pairing, vacuous while no bindings exist but recorded so a fork that adds one lands in the right frame; CompileController is frame-blind, so no artifact states it.
- Dependencies and assets: none beyond `built/`. No menu — the channel is correctly frontless, an infrastructure module with no wearer-facing control.

## Before you compose it

- **The standalone prefab is single-instance**: the interface names are `globalParams`, so two instances collide on them. To run several channels, or to embed one inside a gimmick module, regenerate with your own word table and channel prefix and merge the emitted layers through that module's own `FullController` with only the names your module exports left global.
- **A host's own list extends by scoping, not by enumerating.** A module or composition embedding the channel writes `YourPrefix/*` plus `!` exclusions on *its* `FullController` rather than copying this entry's names across. A copied enumeration goes stale in silence when a name it copied is renamed upstream — the stale entry is dropped without a word while the new name takes an instance prefix, and any cross-controller link on it severs with the build still green (`../../docs/gimmicks.md` §Packaging and interface owns the grammar and the exclusions a wildcard still needs).
- **Producers write the word params, never the wire.** A wide value is split into byte words by the producer (drivers can compare and add constants but not add two params, so limb-splitting is the producer's side of the contract); consumers on the remote side reassemble with the `Pos/Assembled` Direct-tree idiom in `controller.yaml`.
- **Gate on `Acquired`, never on a `Cycle` threshold.** Under `atomic: batch` a receiver re-locks at any exact counter value rather than at a loop head, so it can enter at a tail and take its first `Cycle` increment after a single batch — any threshold on the counter is discipline-dependent, while `Acquired` is certified by a tail copying a flag only a head sets and so behaves the same under both.
- **This entry is generated output.** `controller.yaml` is written by `generate.py` from its `CONFIG` block — edit the config, rerun, recompile `built/`; never hand-edit the YAML **committed here**, which must regenerate byte-identical for the same config. That discipline is about this copy: `build(config)` into your own project makes the emitted document yours, and deviating there is fine as a commented transform in your build script, never a silent edit.

## Measured

**The pause residual.** A culled receiver's animator stops evaluating while the wire keeps updating (the view-cull half of that exposure is removable — compose `anti-cull`, one entry over; distance-hide is not defeatable), and a finite counter cannot distinguish an unbounded pause from continuous progress — so under `set`, a pause that resumes with the counter aliased (at the frozen state's own value or its successor) while frozen in a non-tail state slips **one** apply mixing whole words from the two snapshots bracketing the pause, corrected at the next apply ≤1 loop later — P ≈ (2/period)·(batchCount−1)/batchCount per resume, 1/4 in the shipped config. Emulator-measured at period 4 (av3emu, clone Animator disabled mid-transfer, words changed during the pause, 8 trials of 0.31–2.27 s): 12 applies, 9 pure, 3 whole-word mixes, **0 split words**, every trial converged. `indexLoops` divides that probability at ~1 index bit per doubling. The `batch` discipline was verified separately (5 pauses, 11 applies, 0 group splits).

**What `group:` is for.** It pins words into one batch so an aliased mix can never split one value's limbs — the shipped config groups `Pos/Hi`+`Pos/Lo`, and a single-pause run of an earlier ungrouped config produced exactly the split-limb corruption the option exists to prevent (`hi` from one snapshot, `lo` from the next — a value neither snapshot ever held). A group may span number and bool words (a 12-bit value = one byte word + four bools): the packer pins both kinds to one batch index, padding bool batches forward (a padded slot is free — the wire params exist every tick regardless), and refuses when declaration order makes alignment impossible.

Slots are the bits↔latency dial. The cost model those slots move — wire bits, state count, full-refresh latency — is computed in `generate.py` and returned in its `facts`; read it there rather than from a copy of the formulas.

## Verifying the install

Cheapest observable: in play mode with av3emu, the runtime mirror lists the interface params under their bare names — the word table, `WordChannel/Acquired`, `Pos/Assembled` — and everything else instance-prefixed (`VF##_WordChannel/Wire/…` with `synced=True`, `VF##_WordChannel/Cycle`). Spawn a remote clone, write any word on the local, and the clone's copy follows within ~0.5 s with `WordChannel/Acquired` true and `VF##_WordChannel/Cycle` climbing ~3.5–4.5/s (one per loop; frame-rate-dependent — ~4.3/s at 60 fps, ~3.75/s at 30 fps). Wrong readings: `Acquired` true with `Cycle` frozen is a receiver that certified once and then wedged; both at zero is one that never reached a tail, and the `Wire/Idx…` bools separate its two causes — frozen means the wire never moved (check the params asset landed), changing means it did and the fault is downstream of it. `Acquired` false on the **wearer** is correct, not a symptom. Bare interface names missing means the `globalParams` list was edited or the module was merged through a foreign controller that re-prefixed them.

One liveness precondition rides the receiver: it advances only on exact successor counter values, so a client whose frame interval approaches the ~0.117 s batch hold (under ~10 fps) skips codes, falls to `Lost` often, and degrades to sporadic applies — declared, not measured. First certification is where that shows, since it needs one contiguous head→tail walk; `Lost` copying `Acquired` back rather than clearing it is what holds the cost to once per reset instead of once per dropped code.

What the emulator structurally cannot show for this entry: real network snapshot loss (av3emu's sampler is lossless — the `Lost` path is exercised only by the induced-pause fixture), and the shipping client's parameter delivery to a distance-hidden avatar's paused animator — the emulator models it as "wire updates, animator doesn't", the design is correct under either delivery semantics, but the in-game alias rate is unmeasured. **`Pos/Assembled` is unobservable on a clone and near-unobservable on the wearer** — the mirror lists the name because it is a declared param, but no AAP write reaches the mirror, and the one door that does read an AAP (`DebugDuplicateAnimator`) attaches to the local runtime and runs without the avatar's drivers, which is this entire receiver, so the sum reads its default there too (`../../docs/emulator.md` owns both halves); on a clone no channel reads an AAP at all (`../mirror-detect/README.md`). To check the remote-side reassembly §Before you compose it prescribes, read the clone's `Pos/Hi` and `Pos/Lo` off the mirror — driver-written, so they do land there — and compute `Hi·256+Lo` yourself, or gate a visible consumer on the assembled value and watch that. The two-client check, when wanted: wear it, have the second client distance-hide and unhide the wearer mid-change, and confirm the words converge within a second of unhide with no stale mixed readings persisting. **Read that off the words themselves, not off `Cycle`** — nothing can observe `Cycle` in-game. The receiver is `!IsLocal`-gated, so `Cycle` never leaves 0 on the wearer, and VRChat's OSC and OSCQuery serve only the local player's own worn avatar (`../../docs/osc.md`); a mirror clone reads `IsLocal` true and runs no StateMachineBehaviours (`../../docs/runtime.md`). The counter is a fixture and emulator instrument only.
