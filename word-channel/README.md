# word-channel (Module)

A declared table of values — bytes, ranged floats, bools — replicated to every remote client over a synced channel narrower than the table, with late-join support and a declared refresh cadence. `generate.py` mints the controller from a word-table config, so the shipped module is one worked configuration: 2 bytes + a ranged float + 4 bools (28 payload bits) over **21 synced bits**, full refresh ~0.23 s at 60 fps.

## Provenance

The protocol is the VRCFury Parameter Compressor's, source-studied from `com.vrcfury.vrcfury` (0.1 s batch cadence plus a guaranteed extra frame, a synced index the receiver routes on, latch double-buffering), generalized to a declared word table and hardened where the pause fixture below broke it. VRLabs **Custom-Object-Sync** (MIT, © VRLabs) is the studied ancestor whose receive-side design this entry rejects: its multi-frame receiver decode walks are the machinery a culling pause interrupts, so here every receive state decodes in one parameter-driver frame. Nothing is ported from either; both are credited as ancestors.

## Ground truth

`controller.yaml` is `generate.py` output — the generator's docstring is the design record for the batch-counter protocol, the four-driver `Acquired` certification, and the three assumptions it rests on. `parameters:` owns the param list and its sync/save flags; the prefab's `globalParams` owns the published set. The seam is a VRCFury `FullController` on the prefab root — no scene bindings, no anchor, composes anywhere under the avatar. `globalParams` is exactly two derived wildcards: `WDemo/*` (the config-chosen word table) and `WordChannel/*`. The wire, the latches and `WC/Cycle` sit under the internal `WC/` prefix, which no published wildcard reaches, so a merged build renames them `VF##_WC/…` with `##` assigned per build — a session-local reading for a fixture, never an address anything binds. No menu — an infrastructure module with no wearer-facing control.

**`WordChannel/Acquired` is the proposition a consumer gates on**, and the one fact only this README states to an outsider: false on animator load, false after a distance-cull pause, true once **this client's** receiver has applied a complete word table since then. It is **receiver-scoped** — false on the wearer forever, whose own words ride their source frame for frame and never touch the decode. Its pause coverage is exactly `IsAnimatorEnabled`'s, which `../../docs/runtime.md` §Parameters tabulates per cull mechanism — view cull is the uncovered one, closed by composing `anti-cull`. It says nothing about whether the applied table is one **coherent** snapshot: an aliased resume yields the whole-word mix measured below, never a missing batch. It does not fall for a receiver wedged in `Lost` or a producer that stopped writing.

## Before you compose it

- **The standalone prefab is single-instance.** The interface names are `globalParams`, so two instances collide. To run several channels, or to embed one in a gimmick module, regenerate with your own word-table, channel and internal prefixes and merge the emitted layers through that module's own `FullController`, leaving only your exported names global.
- **A host's own list is two wildcards, never an enumeration.** Publish `WDemo/*` (renamed to your table) plus `WordChannel/*`; everything internal sits under `WC/` and needs no `!` exclusion. An enumeration goes stale in silence when an upstream name is renamed — the copied entry is dropped and any cross-controller link on it severs with the build still green — and an exclusion fails the opposite way, silently widening to expose what it withheld once its stem stops matching (`../../docs/gimmicks.md` §Packaging and interface owns the grammar).
- **Producers write the word params, never the wire.** A wide value is split into byte words by the producer (drivers compare and add constants but cannot add two params); remote-side consumers reassemble with the `WDemo/Pos/Assembled` Direct-tree idiom in `controller.yaml`.
- **This entry is generated output.** `controller.yaml` is `generate.py`'s emission from its `CONFIG` block — edit the config, rerun, recompile `built/`; never hand-edit the committed YAML, which a regenerated one reproduces byte-for-byte for the same config. That constraint governs this copy only: `build(config)` into your own project makes the document yours, and deviating there is fine as a commented transform in your build script, never a silent edit. Freshness is regenerate-and-read-`git diff`; run `generate.py --check`.
- **VRCFury's Parameter Compressor never double-multiplexes the wire.** On an overflowing host avatar it compresses only menu-driven params (`ParameterCompressorSolverService.GetParamsToOptimize` skips any param not `usedInMenu`), and the wire params drive no menu.

## Measured — the pause residual

Under `set` (shipped), a receiver culled mid-transfer and resumed with the counter aliased (at the frozen value or its successor) while frozen in a non-tail state slips **one** apply mixing whole words from the two snapshots bracketing the pause, corrected at the next apply ≤1 loop later — P ≈ (2/period)·(batchCount−1)/batchCount per resume, 1/4 in the shipped config. Emulator-measured at period 4 (av3emu, clone Animator disabled mid-transfer, words changed during the pause, 8 trials of 0.31–2.27 s): 12 applies, 9 pure, 3 whole-word mixes, **0 split words**, every trial converged. `indexLoops` divides that probability at ~1 index bit per doubling; it is inert under `atomic: batch`, which has no pause-alias artifact and re-locks at any counter value.

`group:` pins words into one batch so an aliased mix can never split a single value's limbs — the shipped config groups `WDemo/Pos/Hi`+`WDemo/Pos/Lo`, and a single-pause run of an earlier **ungrouped** config produced exactly the split-limb corruption the option exists to prevent (`hi` from one snapshot, `lo` from the next — a value neither ever held). The `batch` discipline was measured separately (5 pauses, 11 applies, 0 group splits).

`set` vs `batch` is the coherence unit. `set` latch-buffers and applies the whole table atomically at the loop tail — no observer sees a torn set in steady state. `batch` applies each batch directly, coherence per batch, no pause-specific artifact, re-locking at any counter value so a missed sync tick costs ~one batch of staleness rather than a loop. Toggle-bus payloads want `set`; grouped measurement payloads usually want `batch`. **A consumer reads `Acquired`, never a `Cycle` threshold** — a `batch` receiver can take its first `Cycle` increment after a single batch, so any counter threshold is mode-dependent, while `Acquired` behaves the same under both disciplines.

## Verifying the install

In play mode with av3emu, the runtime mirror lists the interface params under their bare names and every `WC/` name instance-prefixed (`VF##_WC/…`). Spawn a remote clone, write any word on the local, and the clone's copy follows within ~0.5 s with `WordChannel/Acquired` true and `VF##_WC/Cycle` climbing (one per loop, frame-rate-dependent — ~4.3/s at 60 fps, ~3.75/s at 30 fps). Wrong readings: `Acquired` true with `Cycle` frozen is a receiver that certified once then wedged; both at zero is one that never reached a tail, and the `Wire/Idx…` bools separate its two causes. `Acquired` false on the **wearer** is correct, not a symptom. Bare interface names missing means `globalParams` was edited or the module was merged through a foreign controller that re-prefixed them.

`WC/Cycle` is a fixture and emulator instrument only. The receiver is `!IsLocal`-gated so `Cycle` stays 0 on the wearer, and VRChat's OSC/OSCQuery serve only the local player's own worn avatar (`../../docs/osc.md`); a mirror clone reads `IsLocal` true and runs no StateMachineBehaviours (`../../docs/runtime.md`). A two-client convergence check — distance-hide and unhide the wearer mid-change, confirm the words converge within a second — reads off the words themselves, never off `Cycle`.

What the emulator structurally cannot show: real network snapshot loss (av3emu's sampler is lossless — the `Lost` path is exercised only by the induced-pause fixture), and the shipping client's parameter delivery to a distance-hidden avatar's paused animator, so the in-game alias rate is unmeasured. **`WDemo/Pos/Assembled` is unobservable on a clone and near-unobservable on the wearer** — the mirror lists the name but no AAP write reaches it. To check the remote-side reassembly, read the clone's `WDemo/Pos/Hi` and `WDemo/Pos/Lo` off the mirror (driver-written, so they land there) and compute `Hi·256+Lo` yourself, or gate a visible consumer on the assembled value (`../../docs/emulator.md`, `../mirror-detect/README.md`).
